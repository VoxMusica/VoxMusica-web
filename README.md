# VoxMusica-server

The backend for voxmusica

## Installation

### Configuration file

You can save your configuration in /config/vmcli.yaml or /config/vmcli.json. The directory can be changed with an env var, [see below](#environement-variables)

### Environement variables

| name | description | example |
|---|---|---|
| CONFIG_DIR | location of the configuration folder. The default value is '/config' | '/config' |
